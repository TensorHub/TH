💡 Design Philosophy

Hierarchical Processing: The architecture implements a "local-to-global" paradigm where:
1️⃣ SAM-base captures fine-grained local details using efficient window attention at high resolution
2️⃣ Compressor aggressively reduces spatial dimensions while preserving semantic information
3️⃣ CLIP-large integrates global context across all compressed tokens for holistic understanding

This design achieves an optimal balance between resolution, memory efficiency, and contextual understanding — enabling high-quality OCR with 16× fewer tokens than traditional approaches.
