TensorHub Memory Bank

Этот репозиторий содержит Банк Памяти проекта. Он служит единственным источником истины для целей, контекста и прогресса проекта.

Рабочий протокол:
- При старте сессии: прочитать файлы в `memory/memory-bank/` и `memory/rules/`.
- После значимых изменений: обновить соответствующие файлы и проверить консистентность.

Структура:
- memory/memory-bank/
- memory/rules/

См. детали в файлах внутри папок.
